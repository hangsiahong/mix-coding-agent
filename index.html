Built for scale.

Advanced agentic capabilities packed into a single script that runs anywhere.

Zero Dependencies

Runs on pure Bash and Python3. No npm install, no venv, no broken environments. Just one 200KB binary.

Agentic Orchestration

Spawn parallel subagents in tmux to hunt bugs, write tests, or refactor code while you stay in the flow.

Native Sandboxing

Isolate tool execution using Linux namespaces (PID, Mount, Net). Safe, lightweight, and fast. No Docker required.

Self-Growing Memory

Automatically extracts architectural lessons and bug fixes into a local wiki (memorybank) for continuous learning.

Multi-Provider

Native support for GitHub Copilot, Google Gemini 2.0/3, and Claude 3.5 Sonnet. Swap models instantly.

Auto-Verification

Automatically runs linters, typecheckers, and tests after every edit. Fixes its own bugs before you see them.
